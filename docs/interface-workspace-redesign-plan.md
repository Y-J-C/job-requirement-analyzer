# 岗位工作台界面优化计划

1. **建立界面基线**：保存首页、岗位方向、审核、汇总的桌面与移动端截图，记录布局和控制台问题。
2. **调整结构语义**：为首页增加流程导览；重组岗位方向页为录入侧栏与记录主区；为页头和操作区补充稳定的结构类名。
3. **重建视觉系统**：更新颜色、字体、间距、边框、按钮、状态标签、表单和列表样式，控制标题尺度和内容宽度。
4. **优化响应式布局**：在 760px 以下恢复单列，重排工具栏与操作按钮，检查 390px 无溢出。
5. **补齐产品细节**：添加站点图标，弱化开发入口，完善状态说明、空状态和悬停/焦点反馈。
6. **分层验证**：先运行相关 Vitest，再执行 ESLint 与 Next.js 构建；最后用真实浏览器复测首页、录入、选择汇总、审核和移动端。

实施按“页面结构 → 样式系统 → 响应式 → 验证”分批完成；每批通过最小测试后再进入下一批。
